*사실*은 그쪽이 맞다. 그러나 **무엇을 해도 되고 무엇을 하면 안 되는지는 이 문서가 정한다.**
둘이 어긋나면 이 문서를 따른다.

**⚠️ 이 저장소는 연습용이다. 그러나 여기 적힌 기준은 고객사 운영시스템을 상정한 것이다.**
_"이 저장소는 연습이니 이 조항은 적용되지 않는다"_ 고 판단하지 않는다.
조항이 이 저장소에 안 맞아 보이면 **그렇게 판단하지 말고, 그렇게 보인다고 보고한다.**

**⚠️ 이 저장소는 공개(public)다.** 커밋하는 모든 글자가 누구에게나 보인다.
토큰·계정·서버 주소·고객사 이름은 **단 한 줄도 쓰지 않는다.**

## 1. 「확장」과 「소스 수정」을 가르는 기준

Payload 는 **남이 만든 프로그램**이다. 32.6만 줄이고 전 세계가 같이 쓴다.
만든 사람들도 쓰는 사람마다 요구가 다르다는 걸 알기 때문에,
프로그램 곳곳에 **"여기에 뭘 끼우세요"라고 미리 구멍을 뚫어놨다.**

|      | 확장                           | 소스 수정                      |
| ---- | ------------------------------ | ------------------------------ |
| 비유 | **콘센트에 가전제품을 꽂는다** | **벽을 뜯고 전선을 새로 깐다** |
| 본체 | 그대로                         | 뜯긴다                         |
| 결과 | 동작한다                       | 동작한다                       |

**결과가 같은 것이 함정이다.** 차이는 나중에 난다 — Payload 가 3.88, 3.89 로 올라갈 때
확장은 그대로 꽂혀 있고, 소스 수정은 **우리가 고친 줄과 저쪽이 고친 줄이 부딪친다.**
버전이 오를수록 빚처럼 쌓이고, 언젠가 _"업그레이드를 포기하자"_ 가 나온다.
그 순간부터 보안 패치도 못 받는다. **대가는 몇 년 뒤 고객이 치른다.**

### 경계선

> **기준은 「코드를 쓰느냐」가 아니다. 「남의 코드를 고치느냐, 정해진 자리에 붙이느냐」다.**

|                 | 무엇                                                              | 판정                                                                   |
| --------------- | ----------------------------------------------------------------- | ---------------------------------------------------------------------- |
| **② 확장**      | 2장의 **확장 지점**에 등록·설정한다. 변경이 그 지점 파일에 그친다 | 새 파일을 100줄 쓰더라도 **②**                                         |
| **③ 소스 수정** | 그 밖의 파일 **내용**을 고친다                                    | `packages/**` 든 `templates/website/src/components/**` 든 **똑같이 ③** |

**⚠️ 「파일을 편집하면 ③」은 틀린 기준이다.**
Payload 에서 확장을 켜려면 **설정 파일 편집이 필수**다. 그 기준을 쓰면 ②가 영원히 나올 수 없다.

**⚠️ ③은 금지가 아니다.** 소스를 고쳐야만 되는 일도 있다.
③은 **「그렇다고 먼저 말하고 승인을 받아야 하는 칸」**이지 하지 말라는 칸이 아니다.

**보기 둘 — 이 저장소에서 실제로 있었던 일이다**

| 요구사항                           | 고친 것                                                                              | 칸    |
| ---------------------------------- | ------------------------------------------------------------------------------------ | ----- |
| _"글 목록을 엑셀로 내려받게 해줘"_ | `templates/website/package.json` + `templates/website/src/plugins/index.ts` **둘뿐** | **②** |
| _"손님이 보는 글자를 한국어로"_    | `app/` · `components/` 의 코드 안 문구 여러 곳                                       | **③** |

## 2. 확장 지점 — 이 저장소의 콘센트

### 2-1. 구멍 넷

|     | 구멍              | 무엇                           | 실물                                           |
| --- | ----------------- | ------------------------------ | ---------------------------------------------- |
| ①   | **설정 파일**     | 기능 스위치판                  | `templates/website/src/payload.config.ts`      |
| ②   | **플러그인 목록** | 기능 덩어리를 통째로 꽂는 자리 | 같은 파일의 `plugins` → `src/plugins/index.ts` |
| ③   | **훅**            | _"저장될 때 이것도 해라"_      | `src/hooks/` · 컬렉션의 `afterChange`          |
| ④   | **화면 끼우기**   | 관리자 화면의 정해진 자리      | `admin.components.beforeLogin` 등              |

### 2-2. 저장소에 **있으나 아직 안 붙은** 것 — 켜기만 하면 되는 후보

`packages/` 안에 소스가 들어 있다. **새로 만들 것이 없다.**

`plugin-import-export`(엑셀 내보내기·가져오기) · `plugin-multi-tenant` · `plugin-mcp` ·
`plugin-sentry` · `plugin-ecommerce` · `plugin-stripe` · `plugin-cloud-storage` ·
저장소 어댑터 6종(`storage-s3` `storage-azure` `storage-gcs` `storage-r2` `storage-uploadthing` `storage-vercel-blob`) ·
`email-nodemailer` · `email-resend` · `richtext-slate`(다른 에디터)

### 2-3. **이미 붙어 있는** 것

`plugin-form-builder`(문의 폼) · `plugin-nested-docs`(분류 계층) · `plugin-redirects`(주소 이전) ·
`plugin-search`(검색) · `plugin-seo` · `richtext-lexical`(에디터)

### 2-4. **이미 켜져 있는 기능** — ①「이미 됩니다」의 재료

- `versions.drafts` 에 **자동저장과 예약발행**이 들어 있다. _"초안으로 뒀다가 승인하면 게시"_ 는 만들 것이 없다.
- 관리자 화면의 한국어 번역(`packages/translations/.../ko.ts`)이 **이미 있다.**
  다만 기본값이 영어 하나라 **설정 두 줄로 켜진다**(②). ⚠️ 컬렉션 설정에 `label:` 로 직접 적힌
  영어 **370곳**은 그것으로 안 바뀐다.

## 3. 용어집 — 화면에 쓰는 한국어

**같은 말은 언제나 같은 한국어로 옮긴다.** 아래 표가 정본이다.

| 영어                  | **쓴다**                 | 쓰지 않는다              |
| --------------------- | ------------------------ | ------------------------ |
| Post / Posts          | **글**                   | 포스트 · 게시물 · 게시글 |
| Page / Pages          | **페이지**               | 쪽 · 문서                |
| Category / Categories | **분류**                 | 카테고리 · 범주          |
| Media                 | **미디어**               | 매체 · 자료              |
| Search                | **검색**                 | 찾기 · 조회              |
| Home                  | **홈**                   | 처음 · 메인              |
| Previous / Next       | **이전 / 다음**          | 뒤로 / 앞으로            |
| Theme                 | **테마**                 | 화면 모드 · 색상         |
| Auto / Light / Dark   | **자동 / 밝게 / 어둡게** | 라이트 / 다크            |
| Dashboard             | **대시보드**             | 관리판 · 현황판          |

**문체 규칙 셋**

1. 안내 문장은 **`~습니다` 체**로 쓴다. (예: _검색 결과가 없습니다._)
2. 버튼·링크는 **짧은 명사나 명령형**으로 쓴다. `~하기`, `~로`. (예: _홈으로_)
3. 표에 없는 말은 **표의 결을 따라** 정하되, 무엇을 어떻게 정했는지 **계획서에 적는다.**

## 4. 건드리지 않는 것

**아래 둘은 ③이 아니라 「하지 않는다」다.** 승인을 받아도 하지 않는다.

|     | 무엇                                                        | 왜                                                                                                                                                                                   |
| --- | ----------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1   | **`pnpm-lock.yaml`**                                        | **1MB · 29,485줄.** 읽으면 대화 맥락이 무너지고, 고치려면 파일 전체를 다시 실어야 해서 올릴 수도 없다. **할 수 있는 일이 아니다 — 필요하면 사람에게 맡긴다**                         |
| 2   | **`.github/` · `test/` · `examples/` · `tools/` · `docs/`** | upstream 이 자기네 개발·배포·문서용으로 쓰는 자리다. **우리 작업 대상이 아니다.** ⚠️ 이 저장소의 실물 화면은 `templates/website/` 아래에 있다 — 고칠 자리를 `test/` 에서 찾지 않는다 |

## 5. 검증 — 이 저장소에서 무엇이 무엇을 잡나

| 층                      | 잡는 것             | 못 잡는 것                                  |
| ----------------------- | ------------------- | ------------------------------------------- |
| **CI (GitHub Actions)** | 문법 · 타입 · 빌드  | _"영어가 남았는지"_ 같은 **내용**은 못 본다 |
| **사람의 화면 확인**    | 눈에 보이는 것 전부 | 화면에 안 그려지는 것                       |

- **에이전트는 로컬 DB·테스트에 닿지 못한다.** 자체 검증 수단은 **CI 하나**다.
- `templates/**` 만 고치면 CI 는 `lint` · `build` 만 돈다. **`pnpm-lock.yaml` 을 건드리면
  50여 개 작업이 한꺼번에 풀린다.**
- ⚠️ **`Content API Tests` 실패는 우리 탓이 아니다.** Payload 본사 AWS 계정에 붙는 단계라
  이 저장소에서는 **구조적으로 통과할 수 없다.** 그것 하나로 작업을 되돌리지 않는다.
